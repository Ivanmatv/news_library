# “News Library”
Journalists upload articles to the news portal website. Each article has an author, but the author can write articles for third‑party platforms and is not part of the website.

## Structure
 - main.py - main file of the application 'News library'
 - article.py - describe article structure
 - author.py - describe author profile
 - news_portal - describe news portal

## Installation

1) Clone repository
```
git clone https://github.com/Ivanmatv/news_library.git
```
2) Change directory
```
cd news_library
```

## Usage 

Launch the application
```
python main.py
```
